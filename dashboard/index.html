📚 How a CDN Works

1

Client Sends Request

A user (you!) requests a file like index.html. The request first hits the Router.

2

Router Load-Balances

The router picks the next Edge Server using round-robin (cycling edge-1 → edge-2 → edge-3 → edge-1…).

3

Edge Checks Cache

The edge checks its in-memory cache. If the file exists and hasn't expired (TTL = 30s), it's a CACHE HIT!

4

Cache Miss → Origin

On a CACHE MISS, the edge fetches the file from the Origin Server, caches it, then serves it.

5

Simulated Latency

Each edge has a regional delay (10/25/50ms) simulating how distance affects response time in a real CDN.

6

Cache Expiry (TTL)

After 30 seconds, cached files expire. The next request will be a MISS again — fetch fresh content from origin.
