Understanding Cache Invalidation

October 2026

There are only two hard things in Computer Science: cache invalidation and naming things. In a CDN, cache invalidation is the process of removing stale content from edge servers so users always get fresh data.

Strategies

  • TTL-based: Content expires after a set time (e.g., 30 seconds). Simple but can serve stale data.
  • Purge: Origin explicitly tells edges to drop specific files. Instant but requires coordination.
  • Stale-while-revalidate: Serve stale content while fetching fresh version in background. Best of both worlds.

How Round-Robin Load Balancing Works

October 2026

Round-robin is the simplest load balancing algorithm. Requests are distributed evenly across servers in a circular order: Server 1 → Server 2 → Server 3 → Server 1 → ...

Pros: Easy to implement, even distribution. Cons: Doesn't account for server load or proximity.

Edge Computing: The Future of CDNs

October 2026

Modern CDNs don't just cache static files — they run code at the edge. Services like Cloudflare Workers and AWS Lambda@Edge allow developers to execute serverless functions close to users, reducing latency for dynamic content too.
